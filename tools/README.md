# BiosimRust Tools

This directory contains visualization and analysis tools for BiosimRust simulation data.

## Epoch Log Visualization

### graphlog.gp

Basic log visualization showing survivors and genetic diversity over time.

**Usage:**

```bash
gnuplot tools/graphlog.gp
```

**Output:** `images/log.png`

**Plots:**

-  Survivors (left Y-axis)
-  Genetic Diversity (right Y-axis)

**Format Support:**

-  Works with both old format (5 columns) and new format with species statistics (13 columns)
-  Only uses first 4 columns, so backward compatible

---

### graphlog-genomeLength.gp

Extended log visualization showing survivors, diversity, and genome length.

**Usage:**

```bash
gnuplot tools/graphlog-genomeLength.gp
```

**Output:** `images/log.png`

**Plots:**

-  Survivors (left Y-axis)
-  Genetic Diversity (right Y-axis)
-  Average Genome Length (right Y-axis)

**Format Support:**

-  Works with both old format (5 columns) and new format with species statistics (13 columns)
-  Uses columns 1-4, so backward compatible

---

### graphlog-species.gp (NEW)

Species statistics visualization showing survivors, diversity, and species count.

**Usage:**

```bash
gnuplot tools/graphlog-species.gp
```

**Output:** `images/log-species.png`

**Plots:**

-  Survivors (left Y-axis)
-  Genetic Diversity (right Y-axis)
-  Species Count (right Y-axis)

**Requirements:**

-  Requires epoch-log.txt with species statistics (13 columns)
-  Will show empty species plot if species statistics not available

---

### graphlog-species-detailed.gp (NEW)

Comprehensive species statistics visualization with multiple panels.

**Usage:**

```bash
gnuplot tools/graphlog-species-detailed.gp
```

**Output:** `images/log-species-detailed.png`

**Plots (4 panels):**

1. **Top Left**: Population and Species Count
   -  Survivors vs. Species Count over time
2. **Top Right**: Species Size Distribution
   -  Average, Largest, and Smallest species sizes
3. **Bottom Left**: Species Turnover
   -  New species created vs. extinct species per generation
4. **Bottom Right**: Species Age and Stagnation
   -  Average species age and stagnation over time

**Requirements:**

-  Requires epoch-log.txt with species statistics (13 columns)
-  All 13 columns must be present

## Neural Network Visualization

### graph-nnet.py

Visualizes neural network structure from `net.txt` file.

**Usage:**

```bash
python3 tools/graph-nnet.py
```

**Requirements:**

-  Python 3 with igraph library: `pip install python-igraph`
-  Input file: `tools/net.txt` (generated by simulator when `displaysamplegenomes > 0`)

**Output:** `tools/net.svg`

**Features:**

-  Color-coded nodes (sensors=blue, actions=pink, neurons=grey)
-  Edge colors based on weight (positive=green, negative=red, zero=grey)
-  Edge width proportional to weight magnitude
-  Automatic layout and sizing based on network complexity

## Epoch Log Format

### Old Format (5 columns) - Backward Compatible

```
generation survivors diversity avg_genome_length murder_count
```

### New Format (13 columns) - With Species Statistics

```
generation survivors diversity avg_genome_length murder_count num_species avg_species_size largest_species smallest_species new_species extinct_species avg_species_age avg_stagnation
```

**Column Descriptions:**

1. **generation** - Generation number
2. **survivors** - Number of surviving individuals
3. **diversity** - Genetic diversity (0.0-1.0)
4. **avg_genome_length** - Average genome length in genes
5. **murder_count** - Deaths from kill gene
6. **num_species** - Number of active species (Phase 6)
7. **avg_species_size** - Average members per species (Phase 6)
8. **largest_species** - Size of largest species (Phase 6)
9. **smallest_species** - Size of smallest species (Phase 6)
10.   **new_species** - New species created this generation (Phase 6)
11.   **extinct_species** - Species that went extinct this generation (Phase 6)
12.   **avg_species_age** - Average age of all species in generations (Phase 6)
13.   **avg_stagnation** - Average stagnation count across species (Phase 6)

**Note:** When speciation is disabled, columns 6-13 will be 0.

---

## Compatibility

All tools are designed to be backward compatible:

-  Tools that only use first 4-5 columns work with both formats
-  New species visualization tools check for column availability
-  Old format logs will still work with all existing tools

---

## Dependencies

-  **gnuplot**: Required for `.gp` scripts
   -  Install: `brew install gnuplot` (macOS) or `apt-get install gnuplot` (Linux)
-  **python-igraph**: Required for `graph-nnet.py`
   -  Install: `pip install python-igraph`
